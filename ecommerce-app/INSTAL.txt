# 1. Install everything
bash scripts/setup.sh

# 2. Set up backend secrets
cp project/backend/.env.example project/backend/.env
# → fill in MONGO_URI and JWT_SECRET

# 3. Start both servers
cd project/backend && npm run dev   # terminal 1
cd project/frontend && npm run dev  # terminal 2

====================
Open http://localhost:5173 — everything proxies through Vite so no CORS issues locally.
PayPal works as soon as you add a PAYPAL_CLIENT_ID from your PayPal Developer sandbox. Without it, 
the app gracefully shows an info message on the order page instead of crashing.
