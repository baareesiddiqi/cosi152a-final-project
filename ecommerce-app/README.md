# COSI 152A — Final Project

This repository contains **ShopWave**, a full-stack e-commerce marketplace built as the capstone project for COSI 152A.

## Quick Start

```bash
bash scripts/setup.sh
```

Then follow the printed instructions to configure `.env` files and start both servers.

## Project Structure

```
.
├── project/
│   ├── backend/     # Express/Node.js REST API
│   ├── frontend/    # React + Vite SPA
│   └── README.md    # Project documentation
├── scripts/
│   ├── setup.sh     # Install all dependencies
│   └── submit.sh    # Commit and push
└── README.md        # This file
```

See `project/README.md` for full documentation.
